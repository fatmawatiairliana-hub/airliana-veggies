# 🥬 AirLiana Veggies

Selamat datang di **AirLiana Veggies**, website toko sayuran segar yang menyediakan berbagai jenis sayur berkualitas, paket sayuran siap masak, serta bumbu dapur dengan harga terjangkau.

---

## 🌿 Tentang Website

AirLiana Veggies merupakan website penjualan sayuran segar berbasis HTML, CSS, dan JavaScript yang dirancang dengan tampilan modern seperti marketplace agar memudahkan pelanggan dalam mencari dan memilih produk.

---

## ✨ Fitur Website

- 🏠 Halaman Beranda Modern
- 🔍 Pencarian Produk
- 🥬 Kategori Sayuran
- 🛒 Keranjang Belanja
- ⭐ Rating Produk
- 🎉 Promo & Diskon
- 🥗 Paket Sayuran Siap Masak
- 📱 Responsive untuk Laptop & Smartphone
- 📞 Order melalui WhatsApp
- 💳 Tampilan seperti Marketplace
